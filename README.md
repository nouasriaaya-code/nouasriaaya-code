## About Me

I'm a Computer Science & Automation student at **Badji Mokhtar University in Annaba, Algeria**, where I study **ISI and Automatics**. I'm drawn to the point where software meets systems: writing code that is clear, logical, and useful.

I enjoy understanding how things work, from low-level programming in C to scripting and web development with Python and PHP. I approach every project with curiosity and a commitment to steady improvement.
